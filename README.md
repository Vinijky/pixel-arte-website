# Pixel Arte — Visual Communication Website

A modern, dark-themed landing page built for **Pixel Arte**, a visual communication company based in Santo Antônio de Pádua, RJ, Brazil. The site showcases services such as labels, signage, banners, and custom prints, with a focus on clean design and fast loading.

## 🚀 Features

- Responsive design (mobile-first)
- Dark theme with blue accent colors
- Direct WhatsApp integration (`wa.me` link)
- Services section with icons
- Portfolio/gallery preview
- About section
- Clean, semantic HTML structure

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox / Grid)

## 📱 Sections

- **Hero** — Main call-to-action with WhatsApp button
- **Services** — Labels, signage, banners, custom prints
- **About** — Company info and values
- **Gallery** — Portfolio preview
- **Footer** — Contact info and social links

## 📦 Getting Started

Clone the repository and open `index.html` in your browser:

\`\`\`bash
git clone https://github.com/your-username/pixel-arte-website.git
cd pixel-arte-website
\`\`\`

No build steps or dependencies required.
